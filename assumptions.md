# Assumptions ledger

The brief: *"You can't ask us questions. That's on purpose. Write down every question you would have asked, and what you decided to assume instead."* Good assumptions count — so each one carries its evidence and a cost-of-being-wrong.

| # | The question I would have asked | What I assumed instead | Evidence / fallback |
| --- | --- | --- | --- |
| 1 | Which date format does each file use? | payments.csv is **day-first** (DD/MM/YYYY); bookings.csv is month-first (MM/DD/YYYY); invoices.csv is ISO. | Cross-file: P5046 (01/09/2026) pays INV-1051, which issued 2026-08-08 — only day-first makes the payment follow the invoice. All payment references land inside sane invoice windows only under this reading; the reverse reading produced impossible "payments before the invoice" cases. |
